# Sales-performance-dashboard-powerbi
Power BI dashboard analyzing sales performance and business insights.
Project Overview
This project analyzes sales performance data to uncover trends in revenue, profit, and customer behavior.
Tools Used
Power BI, Microsoft Excel.
Key Metrics
Revenue: 3M
COGS: 2M
Profit: 932K
Customers: 250.
Key Insights
Apple generated the highest profit
Medium-income customers contributed the most profit
Customer count decreased from May to July
Revenue dropped from 2020 to 2022
